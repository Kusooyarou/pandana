## Структура реализации

### Архитектура
```
Python Layer (pandana/network.py)
    ↓
Cython Layer (src/cyaccess.pyx)
    ↓
C++ Layer (src/graphalg.cpp, src/accessibility.cpp)
    ↓
Contraction Hierarchies (вычисление путей)
```

### Ключевые компоненты

#### Python API
- `Network.set_trip_ids()` - установка trip_ids для рёбер
- `Network.shortest_paths(trip_id=True)` - получение путей в виде trip_ids

#### C++ Core
- `Graphalg.RouteWithTripIds()` - вычисление путей с trip_ids
- `Accessibility.accessibilityVars` - хранение trip_ids
- Сопоставление рёбер с trip_ids

```bash
pip install "numpy<2.0"
```

### 2. Базовое использование
```python
import pandana as pdna

# Создание сети
network = pdna.Network(nodes_x, nodes_y, edges_from, edges_to, edges_distance)

# Установка trip_ids
network.set_trip_ids([101, 102, 103, 104])

# Получение путей в виде trip_ids
trip_paths = network.shortest_paths(origins, destinations, trip_id=True)
```
